## What was measured

The fixture is the one the VOS note measures: `contracts/state-machine/fixtures/valid/recorded-input-route-chosen-three-parts.json`
(3 parts, 9 segments). The test reads it as a `RecordedInput`, submits it to a fresh store after one earlier input
(so the log's format entry is not in the count), and reads the log's growth.

```text
G-32 fixture: recorded-input-route-chosen-three-parts.json (3 parts), input JSON 2130 bytes, state JSON 2636 bytes, record JSON 4818 bytes, the log's frame 4852 bytes (payload 4844 of the 67108864-byte cap, behind an 8-byte header)
```

The input (2,130 bytes) and the state (2,636) are the sizes the VOS note gives for the same fixture. The record, the
two together in `TransitionRecord`'s JSON, is 4,818 bytes; the frame's payload, that record in its log-entry
envelope, is 4,844 bytes, 0.007% of the store's one cap. Result for `G-32`: pass, with this record as the evidence
and the frame-edge measurement of `EXP-1-pb-20261107-2` as extra.
